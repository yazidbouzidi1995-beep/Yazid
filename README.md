# مطاحن الزيبان القنطرة - إدارة نقاط البيع

## التطبيق الرئيسي

تطبيق إدارة متكامل لنقاط البيع في شركة مطاحن الزيبان القنطرة.

### المميزات الرئيسية:

1. **حماية بـ PIN** - كلمة سر من 4 أرقام
2. **المخزونات** - 3 أنواع (مطحنة/خارجية/نقاط البيع)
3. **الطلبات** - إدارة طلبات البائعين
4. **نقاط البيع** - إضافة/تعديل/تجميد/حذف
5. **المنتجات** - إدارة المنتجات مع سعات متعددة
6. **التحويلات** - 5 أنواع (تحويل/طلبات/استقبال/إرجاع/تخلص)
7. **المبيعات** - تقارير بالفترات
8. **الرسائل** - تواصل مع البائعين
9. **مشاركة التطبيق** - إرسال التطبيقات الأخرى

### الألوان:
- الأخضر: #2E7D32 (اللون الرئيسي)
- البرتقالي: #F57C00 (اللون الثانوي)

### التثبيت:

```bash
# تثبيت التبعيات
flutter pub get

# بناء APK
flutter build apk --release
```

### الملفات المهمة:
- `lib/main.dart` - نقطة الدخول
- `lib/features/` - الميزات المختلفة
- `lib/core/theme/` - الألوان والتصميم

### التطبيقات المرتبطة:
1. تطبيق البائعين (سيتم بناؤه لاحقًا)
2. تطبيق المراقبة (سيتم بناؤه لاحقًا)
